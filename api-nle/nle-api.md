## API

**Application Programming Interface (API)** adalah jalur koneksi antar sistem yang memungkinkan dua sistem berbeda saling bertukar data dan informasi. National Logistics Ecosystem membuka akses koneksi sistem dengan pihak Pemerintah dan Swasta melalui **API NLE**. Layanan ini diberikan untuk memberikan kemudahan pada pihak eksternal dalam menjalankan proses layanan logistik, seperti kirim dokumen, mendapatkan status dan respon dokumen, dan mengecek referensi (kurs, larangan pembatasan, tarif, pelabuhan dan manifes) dari *platform* maupun *host-to-host.*
