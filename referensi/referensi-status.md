# Referensi Status Pengajuan Dokumen

Berikut ini merupakan tabel referensi kode status alur dokumen pabean dan cukai pada sistem CEISA 4.0

| KODE STATUS | NAMA STATUS | DESKRIPSI |
| --- | --- | --- |
| 100 | DRAFT | Dokumen baru dibuat dan belum dikirim |
| 200 | KIRIM / SUBMIT | Dokumen telah dikirim ke sistem CEISA 4.0 |
| 300 | VALIDASI | Dokumen sedang dalam proses validasi sistem |
| 400 | BILLING | Kode billing diterbitkan untuk pembayaran pungutan |
| 500 | PENDAFTARAN | Dokumen mendapatkan Nomor dan Tanggal Pendaftaran |
| 600 | PENETAPAN | Pemeriksaan dan penetapan jalur (Hijau / Kuning / Merah) |
| 700 | SELESAI / SPPB | Surat Persetujuan Pengeluaran Barang diterbitkan |
