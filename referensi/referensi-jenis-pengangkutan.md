# Referensi Jenis Pengangkutan

Berikut ini merupakan tabel referensi moda transportasi/pengangkutan pada sistem CEISA 4.0

| KODE MODA | NAMA MODA PENGANGKUTAN | KETERANGAN |
| --- | --- | --- |
| 1 | LAUT | Pengangkutan melalui jalur laut / kapal |
| 2 | KERETA API | Pengangkutan melalui jalur kereta api |
| 3 | DARAT | Pengangkutan melalui jalur darat / truk |
| 4 | UDARA | Pengangkutan melalui jalur udara / pesawat |
| 5 | POS / KURIR | Pengangkutan melalui jasa kiriman pos / ekspedisi |
