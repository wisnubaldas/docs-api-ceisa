# Referensi Fasilitas Tarif

Berikut ini merupakan tabel referensi kode jenis fasilitas tarif bea masuk / pajak pada sistem CEISA 4.0

| KODE FASILITAS | NAMA FASILITAS TARIF | KETERANGAN |
| --- | --- | --- |
| 1 | KERINGANAN | Pemotongan tarif bea masuk / pajak |
| 2 | PEMBEBASAN | Pembebasan 100% bea masuk / pajak |
| 3 | TIDAK DIPUNGUT | Fasilitas tidak dipungut pajak/bea |
| 4 | DITANGGUNG PEMERINTAH (DTP) | Bea masuk / pajak ditanggung pemerintah |
| 5 | PENUNDAAN | Penundaan pembayaran bea masuk / pajak |
