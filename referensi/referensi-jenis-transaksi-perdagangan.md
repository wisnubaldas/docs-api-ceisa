# Referensi Jenis Transaksi Perdagangan

Berikut ini merupakan tabel referensi jenis transaksi perdagangan yang ada untuk kegiatan kepabeanan dan cukai pada sistem CEISA 4.0

| KODE_JENIS_TRANSAKSI_PERDAGANGAN | `**URAIAN**` |
| --- | --- |
| IMB | Transaksi Perdagangan Dengan Imbal Dagang |
| IOA | Pembayaran Dilakukan Dengan Interoffice Account |
| KMD | Pembayaran Kemudian |
| KON | Pembayaran Dilakukan Dengan Konsinyasi |
| LAI | Transaksi Perdagangan Atau Cara Pembayaran Lainnya |
| PMK | Pembayaran Dilakukan Dimuka |
| RLC | Pembayaran Dengan Red Clause Letter Of Credit |
| SLC | Pembayaran Dengan Sight Letter Of Credit |
| ULC | Pembayaran Dengan Usance Letter Of Credit |
| WSI | Pembayaran Dilakukan Dengan Wesel Inkaso |
