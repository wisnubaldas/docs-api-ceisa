# Referensi Satuan Barang

Berikut ini merupakan tabel referensi kode satuan barang yang digunakan pada sistem CEISA 4.0

| KODE SATUAN | NAMA SATUAN | KETERANGAN |
| --- | --- | --- |
| PCE | Piece / Buah | Satuan hitung barang jumlah fisik |
| KGM | Kilogram | Satuan berat standar SI |
| TNE | Tonne / Ton | Satuan berat 1.000 kg |
| LTR | Liter | Satuan volume cairan |
| MTR | Meter | Satuan panjang |
| CMT | Centimeter | Satuan panjang 0,01 meter |
| MTK | Square Meter / M2 | Satuan luas |
| MTQ | Cubic Meter / M3 | Satuan volume |
| SET | Set | Satuan kelengkapan barang |
| DZN | Dozen / Lusin | Satuan jumlah 12 pcs |
| BOX | Box / Kotak | Satuan kemasan/kemasan isi |
| CTN | Carton / Karton | Satuan kemasan dus |
| TGM | Thousand Grams | Satuan berat 1.000 gram |
| GRM | Gram | Satuan berat gram |
