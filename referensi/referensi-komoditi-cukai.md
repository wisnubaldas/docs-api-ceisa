# Referensi Komoditi Cukai

Berikut ini merupakan tabel referensi jenis komoditi Barang Kena Cukai (BKC) pada sistem CEISA 4.0

| KODE BKC | NAMA KOMODITI CUKAI | KETERANGAN |
| --- | --- | --- |
| HT | HASIL TEMBAKAU | Rokok, Cerutu, Rokok Elektrik, HPTL |
| EA | ETIL ALKOHOL | Etil Alkohol / Etanol murni atau teknis |
| MMEA | MINUMAN MENGANDUNG ETIL ALKOHOL | Minuman beralkohol / miras (Golongan A, B, C) |
